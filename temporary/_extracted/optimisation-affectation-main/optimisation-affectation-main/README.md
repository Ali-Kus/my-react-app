# Installation

Here we use the [Quarto environment](https://quarto.org/)
(RMarkdown on steroid) that you'll need to setup on your own,
with either [RStudio](https://posit.co/download/rstudio-desktop/)
or [VSCode](https://code.visualstudio.com/)
(+ [extension](https://quarto.org/docs/tools/vscode.html)).

## Dependencies

We also use a [special extension](https://github.com/jjallaire/code-visibility#readme)
to hide some debug calls in our notebook cells.
You shouldn't nedd to install it since it has been added
into the repositery, but just in case you'll need:

```bash
$ quarto install extension jjallaire/code-visibility
```
