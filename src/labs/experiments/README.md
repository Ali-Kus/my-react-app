# Labs — expériences

Bac à sable. On dépose ici un composant par expérience (ex. `RippleField.jsx`,
`GooeyBlobs.jsx`…), puis on le branche dans la grille de `../LabsApp.jsx`.

Règles du coin :

- Tout reste **isolé** dans `src/labs/` — pas d'import depuis le portfolio,
  pas de style qui fuit (préfixer les classes en `.labs-…` ou scoper au
  composant).
- Le bordel est autorisé **ici** : prototypes, code jetable, idées non finies.
- Si une expérience devient « propre » et mérite le portfolio, on la sort de
  ce dossier à ce moment-là.
